# 三者叠加验证：解析闭式 O2cal + S2-b12 相机 + dc 模式

- **日期**：2026-11-25
- **产物**：`run_stack_verify.sh`、`timing/o2_stack.csv`（21 run）
- **结论**：**三者完全可叠加**。`analytic` 在 `S2-b12` 之上再贡献 **+0.0143 dB（s0）/ +0.0187 dB（dc）**，7/7 场景全正；最终 **7 场景平均保留率 93.8%，最小值 80.7%，全部 ≥80%**（在 grid 版本上 bicycle/train 曾分别只有 79.7%/80.3%）。

## 四、结论

1. **三者正交可叠加**：相机（S2-b12，+0.037）× 求解器（analytic，+0.014）互不干扰，总增益 ≈ 两者之和。
2. **求解器改进与 SH 模式正交**：dc 下同样 +0.019。
3. **终版配置**：
   ```
   --av-core-aabb 0.80 --av-no-scale-gate --av-cover-target gauss --av-gauss-probe 20000
   --av-pos-mode dual_domain --av-pos-b 12 --o2-cams auto_virt
   --o2-solver analytic --o2-cf-agg eq
   ```
4. **遗留项**：`room` 的 `dc + grid` 单元 eval 失败（PSNR 空），不影响结论（同场景 analytic 有值，且 s0 组齐全）。
