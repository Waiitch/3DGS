## 3. 三点发现

1. **网格已收敛**：`G_fine` 与 `G_def` 只差 0.004 dB ⇒ 0.13–0.17 dB 的差距**不是网格离散误差**，而是**目标函数本身不同**。
2. **闭式解的 α 系统性偏高**：`am_mean_pre_cal` truck 0.8238 → **0.8462**、room 0.8875 → **0.9001**。原因是 9×9 网格只在合并高斯的 ±1.25σ 归一化局部框内积分，而闭式解积满全平面——**远场区域（合并高斯弱、但 `a_ref` 仍非零）把网格的 α 拉低，闭式解则包含它**。
3. **β 与会话预期相反**：β 增大（更聚焦核心）只是让 PSNR 单调变差（β=0 最好）。说明"核心聚焦"并不是网格占优的原因；网格的优势来自**截断而非加权**，而截断无法在闭式框架里复刻（除非改成有限支撑积分，那就失去解析性）。

## 4. 裁决（对照 §4.2）

| 档位 | 判据 | 实测 | 结论 |
|---|---|---|---|
| 直接晋级 | ΔPSNR ≥ −0.005 | −0.134 / −0.165 | ❌ |
| 条件调优 | 掉 0.01–0.03 但加速 ≥2× | 掉 0.13–0.17（加速 2.6×/1.9×） | ❌ 掉点过大 |
| **淘汰保留原网格** | 稳定掉点 > 0.03 | **是** | ✅ **采纳本档** |

**最终建议**：默认维持 `grid=9, sigma_cut=1.25`；解析闭式解及其 1e-15 精度验证作为**消融分析**保留（可用于论文"网格离散误差可忽略"的论据），但**不替换默认**。

## 5. 本地适配差异

| 参考方案 | 本地实现 | 说明 |
|---|---|---|
| 独立脚本读 pair 缓存 | 直接接在 `o2gpu.opacity_o2cal_gpu` 内（`--o2-solver analytic`） | 复用同一 `_project`，避免重复投影 |
| 自带投影 | 复用 `o2gpu._project`（已含 EWA `+0.3I`） | 口径与网格路径完全一致 |
| 显式构造 `Σ̃_m` 矩阵 | 只存标量 `tsm00/tsm01/tsm11`（乘 `1/(1+β)`） | 省内存，等价 |
| 有效性掩码 | 复用网格路径的 `ok`（`sigma_cut` 决定 footprint 半径） | **必须同时传 `--o2-sigma-cut 1.25`**，否则掩码全灭（本轮踩过：传 0 导致 `o2_views=0`、全部回落 `a0`、PSNR 精确等于 O0） |
