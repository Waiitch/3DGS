### `den_v` 与几何量的相关性（**决定性证据**，n = 73272）

| 对照量 | Spearman ρ | 比值 CV |
|---|---:|---:|
| 常数 1 | —（无方差） | — |
| `sqrt(det Σ_m)`（面积） | **−0.166** | 2.007 |
| **`1/κ = sqrt(λmin/λmax)`** | **+0.982** | 55.48 |
| `1/λmax` | +0.496 | 164.8 |

→ **方案的 H2 前提被完全证实**：9×9 网格铺在**各向同性像素方框**上，其每视角分母 `den_v` 确实按 **`1/κ`** 加权（ρ=0.982），而不是按面积（ρ=−0.166）。

### ⚠️ 关于 48.6% 掩码不一致（必须如实记录）

两个 dump 的 `valid` **总数几乎相同**（137006 vs 136999，均 52.26%）但**位置错开**（grid-only 63734、cf-only 63727）。这说明两次运行拿到的 **pair 批次顺序不同**（本次 dump 只抓首个 batch，而两条求解路径的 pass-1 pair 枚举顺序未能对齐）。因此：

- **表 D1 的配对统计（单视角 MAE、多视角 MAE、神谕检验）不可信**，只能作参考；
- **可信的是**：① `den_v` 与 `1/κ` 的相关性（逐视角局部量，不依赖配对）；② 下面 D3 的端到端结果（各臂独立完整运行）。

**附带发现**：dump 里 `Σ_m` 出现 **1.3e41** 量级的元素——存在近退化投影（合并高斯几乎落在相机平面，`tz→0`）。网格路径在其有限方框内仍给出有限比值（`den_v` 中位数 10.57），闭式解则趋近 0，**这是两条路径在病态视角上的又一处系统性分歧**。

## 裁决：情形 B

| 判据 | 实测 | 结论 |
|---|---|---|
| 情形 A：修复后 ≥ −0.01 dB 且加速 ≥2.5× | 修复后 −0.124 dB | ❌ |
| **情形 B：闭式与超密网格一致，但两者都输给 9×9** | 单视角 MAE 本就 0.315（闭式与网格在单视角层面就分歧），且 `ecc` 只能挽回 0.03 dB | ✅ **采纳** |
| 情形 C：纯截断差异 | `G_fine`（2.0σ）≈ `G_def` 已排除纯截断 | ❌ |

**科学结论**：现行 `9×9, sigma_cut=1.25` 的收益**不是**来自"更接近真值"，而是来自三处**系统性的欠采样/病态处理**，它们在合并椭球高度扁平、掠射、或近退化投影时**恰好抑制了不透明度高估**：

1. **短轴欠采样**：方框步长 `2.5/8 = 0.3125·sqrt(λmax)`，对 κ>3 的高斯短轴方向采样严重不足 → 单视角 α 偏低；
2. **`1/κ` 隐式权重**：把上述偏差最大的掠射视角自动降权（ρ=0.982）；
3. **近退化视角（`Σ_m ~ 1e41`）**：网格给出有限比值，闭式趋 0。

三者叠加产生了一个**近似但偏差方向恰好有利**的估计器。精确闭式解在数学上正确（Phase 0 已达 1e-15），但**去掉了这些"有益的偏差"**，所以端到端反而更差。

**行动**：`grid=9, sigma_cut=1.25` 保留为默认；`CF_ecc` 与 `--o2-solver analytic` 作为**理论极限对照**保留在代码里（默认关闭），论文中可用来论证"网格欠采样提供了有益正则化"这一非平凡结论。
